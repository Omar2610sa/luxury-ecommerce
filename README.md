# 🛍️ Luxury E-Commerce

A modern luxury e-commerce web application built with cutting-edge technologies.

## 🚀 Tech Stack

- **Next.js** — React framework with App Router & SSR
- **TypeScript** — Type-safe codebase
- **Tailwind CSS** — Utility-first styling
- **shadcn/ui** — Accessible, customizable UI components
- **i18next** — Internationalization (Arabic / English)

## ✨ Features

- 🌐 Multi-language support (AR / EN)
- 🛒 Shopping cart & checkout flow
- ❤️ Favorites / Wishlist
- 📦 Order tracking & shipping info
- 💳 Payment methods management
- 📍 Address management with Google Maps
- 🔐 Authentication (login / register)
- 📱 Fully responsive design
